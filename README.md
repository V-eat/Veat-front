# Front de l'application Veat

Veat est une application de commande de plats au restaurant, pensée pour réduire l’attente grâce à la préparation en amont.

## Fonctionnalités

### Côté client

- Parcourir les restaurants et leurs menus
- Ajouter des plats au panier et passer commande
- Suivre ses commandes et consulter l’historique
- Gérer son profil, ses allergies, ses favoris et ses paramètres

### Côté restaurateur

- Créer le profil de son restaurant
- Gérer les plats du menu (création, édition, disponibilité)
- Suivre et gérer les commandes reçues

## Démarrer le projet

1. Créer le fichier `.env` à partir de `.env.example`
2. Installer les dépendances
3. Lancer le serveur de dev

```bash
cp .env.example .env
npm install
npm run dev
```
